# Karar paneli demosu

Tarayıcıda çalışan, tek dosyalık etkileşimli bir karar paneli: altı soğutma seçeneği, 175 hava × şebeke senaryosu, Pareto süzgeci ve ağırlıklı toplam.

Canlı sayfa: https://mustafabugrabekdemir.github.io/mavi-pano/

Kurulum gerekmez; `index.html` dosyası indirilip tarayıcıda da açılabilir.
